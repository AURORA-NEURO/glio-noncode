- [ ] one positive and three controls per operation

- [ ] CRISPR mode and guide budgets are checked
- [ ] target sequences are validated

- [ ] editing windows are enforced
- [ ] prime edit length and flank bounds are enforced
- [ ] reporter reference/alternate pairs are required
- [ ] construct budgets are enforced
- [ ] controls and readouts are required

## Release

- [ ] five checks per row
- [ ] runtime stages are unique and contiguous
- [ ] replay and integrity receipts are present
- [ ] CI runs CLI and focused tests
- [ ] 5k+ coherent build is committed to main
