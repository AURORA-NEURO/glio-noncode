# Validation-design frontier assurance

The assurance planes make the planning surface inspectable at several levels:

- source and public-boundary checks
- schema and adapter compatibility
- operation and row evaluation
- state and issue reconciliation
- content-address integrity
- positive/control coverage
- source-to-execution evidence joins
- review routing and handoff
- failure rehearsal
- resource accounting
- release bundle closure

The ordered runtime exposes seventy-nine stage receipts. Each stage records sequence, elapsed milliseconds, output address, detail, and its own content address. The final acceptance decision is the conjunction of the core gates and every assurance plane.

This structure supports local replay without any hidden session state. It also keeps unsupported interpretations outside the planning result.
