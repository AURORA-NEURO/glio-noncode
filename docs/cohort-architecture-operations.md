# D12 Operation Map

The D12 operation map binds each semantic operation to its family evaluator operation, plane, inputs, outputs, source joins, control policy, and four-case scenario matrix.

| IDs | Family | Operations | Plane |
| --- | --- | --- | --- |
| C01-C04 | Foundation | cohort query, background rate, sequence control, chromatin control | cohort foundation |
| C05-C08 | Beta | regulatory recurrence, regional burden, functional convergence, pathway or regulon convergence | cohort convergence |
| C09-C12 | Alpha | clonality timing, primary recurrence, treatment selection, cross-cohort replication | cohort longitudinal |
| C13-C16 | Frontier | subgroup fairness, transportability, federated summary, cohort discovery | cohort release |

## Delegate retention

The aggregate calls the pinned family fixtures and evaluators to rebuild normalized delegate rows. A case stores the delegate fixture identifier, record identifier, family operation, exact context, control class, source references, bounded input payload, evaluator output, and delegate output address. The aggregate execution then compares observed state, issue codes, source counts, payload field counts, and row counts against the case contract.

## Control semantics

Foundation controls use the family’s ordered control records. Beta controls retain absence, foreign context, incomplete control, and contradictory control states. Alpha controls retain incomplete phase, foreign context, empty input, and ambiguous direction paths. Frontier controls retain parity gaps, feature shift, privacy floors, empty inputs, invalid inputs, and discovery identity failures.

Controls are not discarded because they do not support a positive result. They are routed to review with priority and required action. Context mismatch, privacy-floor failure, phase incompleteness, and invalid inputs remain explicit in the public receipt.

## Claim ceiling

Recurrence is a descriptive count. Burden is a callable-space comparison. Convergence is a bounded feature or set contrast. Longitudinal records show declared phase and frequency relationships. Fairness, transport, and federated summaries expose their own thresholds and gaps. Cohort discovery is a publication bundle over aggregate feature identities. None of these operations alone establishes a mechanism, prognosis, treatment choice, benefit, resistance, or transportability.
